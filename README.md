# King Hustle Plan Website

A mobile-first static website prototype for KingHustlePlan.com, built for Caper Enterprises LLC.

## Framework
- Static HTML generated by Node.js scripts
- Mobile-first responsive CSS
- Accessible expandable mobile navigation
- No database, authentication, payment processor, or runtime dependencies
- Static-first pages suitable for Squarespace implementation reference or separate hosting

## Run locally
```bash
npm install
npm run build
npm run dev
npm run lint
npm run typecheck
npm run check:content
```

## Owner configuration
Edit `config/site-config.json` to replace placeholder checkout links, contact email, and any real social URLs. Purchase buttons read from this file. Missing checkout/contact values do not expose fake customer-facing information.

## Main copy locations
- Homepage: generated by `scripts/build.mjs` and documented in `HOMEPAGE_COPY.md`
- Product copy: `PRODUCT_COPY.md` and generated product pages in `dist/products/`
- FAQ: `FAQ.md` and generated FAQ page in `dist/faq/`
- Legal placeholders: `LEGAL_REVIEW_REQUIRED.md` and generated policy pages in `dist/`
- Screenshots: `screenshots/`
- Handoff ZIP: `king-hustle-plan-website-v2.zip`
